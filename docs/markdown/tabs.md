Tabs can be created using the custom syntax `§§§`.
Titles of the tabs are set after the `§§§` marker, the last tab is terminated with an empty `§§§`.
Any content between the markers are rendered as the tab content.

Example:

```md
§§§ Dog breeds

Common dog breeds:

- Labrador Retriever
- German Shepherd Dog
- Dachshund

§§§ Cat breeds

Common cat breeds:

- Ragdoll
- Maine Coon
- British Shorthair

§§§ Fruits

These are types of fruit:

- Banana
- Apple
- Orange

§§§ Flowers

These are some flowers:

- Rose
- Tulip
- Sunflower

§§§ Sports

Some common sports:

- Football
- Basketball
- Golf

§§§
```

Above will be rendered as:

§§§ Dog breeds

Common dog breeds:

- Labrador Retriever
- German Shepherd Dog
- Dachshund

§§§ Cat breeds

Common cat breeds:

- Ragdoll
- Maine Coon
- British Shorthair

§§§ Fruits

These are types of fruit:

- Banana
- Apple
- Orange

§§§ Flowers

These are some flowers:

- Rose
- Tulip
- Sunflower

§§§ Sports

Some common sports:

- Football
- Basketball
- Golf

§§§
